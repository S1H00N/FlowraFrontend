# Flowra 프로젝트 관리 통합 UI/UX 최종 디자인 v2

**용도:** Flowra React + TypeScript 구현 전에 화면 구조·디자인·상호작용을 확정하기 위한 브라우저 실행형 UI 레퍼런스.

## 시작하기

- `Flowra_UIUX_v2_인터랙티브.html`을 열면 설치 없이 주요 화면을 확인할 수 있습니다.
- `index.html`은 `styles.css`, `app.js`, `v2.css`, `v2.js`를 불러오는 원본 구조입니다.
- 브라우저에서 프로젝트 목록/상세, 개요, 업무 목록, 간트 차트, 구성원, 관리자 전체 현황/프로젝트 목록/업무량을 전환해 보세요.
- 샘플 데이터의 생성·수정·배정은 **현재 탭의 로컬 메모리 화면에만 반영**되며, 서버·계정·메일·프로젝트에는 전혀 변경을 가하지 않습니다. 브라우저를 새로고침하면 초기화됩니다.

## 이전 버전 대비 재검토 및 적용

| 기존 누락·문제 | v2 반영 |
|---|---|
| 고정 좌표 간트 일정 바 | `from/to` 날짜 기반 위치·너비 계산. 일·주·월 분리, 월별 실제 일수 반영 |
| Dependency 표시 없음 | 업무 ID 연계 선행→후행 점선 표시, ON/OFF 옵션 |
| 기간 미설정과 한쪽 날짜 없음 | 간트의 별도 빈 상태/날짜 마커, 기간 미정 필터 |
| 트리 보조 옵션 부족 | 상태·우선순위·담당자 검색, 적용 필터 칩, 표시 옵션(행 밀도/컬럼) |
| 관리자 전체 현황 수치와 하위 화면의 연결 약함 | 관리자 KPI, 프로젝트 상태/일정 위험 분리, 검색·필터, 업무 배정 샘플 히트맵, 미배정 목록 |
| 회사 참여자/프로젝트 참여자 초대 흐름 불완전 | 회사 멤버 목록→추가 확인→프로젝트 참여 상태→업무 배정의 UI 흐름 |
| 생성 모달 고급 필드 누락 | 실적 기간·마감일시·수동 진행률·WBS·정렬 순서 표시 |
| 프로젝트 개요 임의 Phase 진행률 | '완료 업무 수/조회 업무 수'로 구분, 서버 진행률과 혼동 금지 |
| 반응형 | 기존 380px 도킹/오버레이·모바일 전체 화면 정책 유지 |

## 디자인 참고 출처와 적용 원칙

- **Linear:** 빠른 목록 탐색, 별도의 Display options. https://linear.app/docs/display-options
- **ClickUp:** 좌측 WBS와 간트 타임라인, 일/주/월, 의존성. https://help.clickup.com/hc/en-us/articles/6310249474967-Create-and-share-a-Gantt-view
- **Asana:** 프로젝트/포트폴리오와 상세 패널 흐름. https://help.asana.com/s/article/portfolios-overview
- **monday.com:** 관리자 프로젝트 전체 현황 대시보드. https://support.monday.com/hc/en-us/articles/23921675672466-Portfolio-management-All-Projects-Dashboard

**가져오지 않은 것:** 모든 보기와 버튼을 한 화면에 노출하는 방식, 데이터 계약을 벗어나는 업무 드래그 저장, API 미지원 충돌/휴가 계산, 기존 Flowra 디자인 시스템을 교체하는 대규모 리브랜딩.

## 구현상 필수 주의

- 이 HTML/JS는 **브라우저 디자인 레퍼런스**입니다. 실제 Flowra 저장소에 자동 반영되지 않았습니다.
- 프로젝트 상태·일정 위험도는 별도 데이터입니다. 서버가 제공하지 않는 위험등급을 만들면 안 됩니다.
- 회사 구성원, 프로젝트 구성원, Work Item Assignment는 별도의 권한·리소스입니다.
- Phase는 Work Item의 부모와 동일한 ID로 취급하면 안 됩니다.
- 최대 5단계, lazy loading, 기존 API·DTO·권한, 날짜 기본 미설정, 부모 기간 클릭 적용, 업무 지연 시 상태 변경 없음, 380px 도킹을 유지해야 합니다.
- 실제 서버에서 지원되지 않는 초대/해제/휴가·반차/충돌/업무량 조작은 UI를 가짜 완료 상태로 연결하지 마세요.
- `CODEX_HANDOFF.md`를 실제 적용 지침으로 참고하세요.

## 검증 기록

- Node.js 구문 검사: `app.js`, `v2.js` 통과.
- 프로젝트 목록, 업무 목록, 간트(일/주/월), 구성원, 관리자 전체 현황/프로젝트 목록/업무량, 개요 HTML 템플릿 생성 검사: 통과.
- 이 작업 환경의 Chromium은 관리자 URL 차단 정책 때문에 자동 브라우저 렌더링/스크린샷 테스트를 수행하지 못했습니다. 따라서 픽셀 단위 시각·반응형·포커스 동작은 사용자의 브라우저에서 추가 확인이 필요합니다.
