# 프로젝트 정리 검토 기록

검토일: 2026-10-02 (Asia/Seoul)

폴더 구조, TypeScript import 관계, 테스트 참조, 패키지 선언, 빌드 설정, 문서와 이미지의 중복 및 참조를 확인했습니다. 작업 시작 시 존재하던 인증·할 일 기능과 문서 변경을 기준으로 검토했으며, 작업 중 사용자가 다른 창에서도 수정하고 있음을 확인했습니다. 다른 창에서 추가로 삭제한 DB 패키지와 로컬 task-board 모듈, 타입 설정 변경은 복원하거나 덮어쓰지 않았습니다.

## 이 작업에서 정리한 내용

| 대상 | 변경과 근거 |
| --- | --- |
| 웹 미사용 파일 52개 | 앱 진입점의 정적·타입·lazy import와 테스트 참조를 확인한 뒤 UI 템플릿 43개, 중복 분류 화면, 미사용 컴포넌트·API·hook·placeholder 제거 |
| 웹 helper와 상수 | 사용되지 않는 날짜·분류 설정 함수, 타입 import, API 정규화 함수와 상수 제거. 기존 분류 저장값의 읽기·정규화 유지 |
| 빈 목업 앱 | 실제 목업 0개인 `artifacts/mockup-sandbox` 제거. 연결된 Replit 8081 포트도 제거 |
| Hello 샘플 패키지 | `scripts/src/hello.ts`와 해당 package/tsconfig 제거. 실제 post-merge 설치 스크립트는 유지 |
| 직접 의존성 39개 | 웹 33개, API 서버 4개, DB 패키지 2개의 미사용 선언 제거. DB 패키지 자체는 이후 다른 창에서 삭제 |
| 잠금 파일 | 현재 6개 package manifest와 대조하고 도달할 수 없는 전이 의존성 89개 제거. 남은 482개 패키지의 버전·무결성 정보 유지 |
| 설정과 빌드 boilerplate | 빈 workspace 경로·자산 별칭, 무효인 웹 package의 pnpm 설정, 사용하지 않는 플랫폼 override, 서버의 미래 패키지 external 목록 제거 |
| UI directive | Vite 앱에 남아 있던 Next.js `use client` 선언 3개 제거 |
| 누적 생성물 | 기존 Playwright 보고서·결과 폴더 33개, 임시 출력물, 개발 로그, 재생성 가능한 QA 집계 파일 제거. 과거 브라우저 결과만 약 120MB |
| 오래된 테스트 조건 | 날짜 버튼의 접근성 이름에 붙는 일정 수를 허용하고, 현재 CSS와 기존 HEAD에 모두 없는 점 장식 검사 제거. 메뉴 위치·표시 여부·가로 넘침 검사는 유지 |

실행 중인 개발 서버가 사용하는 로그 2개는 유지했습니다. 사용 중인 패키지의 `node_modules`와 필요한 로컬 도구·환경 파일, 문서가 참조하는 QA 증거 이미지, 설계 기록 및 고유 산출물은 보존했습니다.

## 확인한 문제와 처리

- 브라우저 테스트에서 날짜 버튼의 실제 이름과 오래된 exact locator가 달라 실패하는 것을 확인하고 선택기를 수정했습니다.
- 연결 할 일의 장식용 점을 요구하는 검사는 현재 화면·CSS와 맞지 않아 해당 조건만 제거했습니다.
- 로그인 기준 이미지는 Google 인증 영역 추가 이전 화면이었고, 메모·공지 기준 이미지는 현재 사이드바 달력이 추가되기 전 화면이었습니다. 현재 화면을 직접 검토하여 기준 이미지 갱신 여부를 판단했습니다.
- 메모 상단 상태 표시가 좁아져 `대기 중`이 세로로 줄바꿈되는 문제를 발견했습니다. 상태 표시의 축소와 줄바꿈을 제한하는 최소 CSS 클래스 변경으로 처리했습니다.
- 보존한 설계 초안 `docs/design/tasks-redesign.md`에는 이미 없는 `tasks-desktop.png`, `tasks-mobile.png` 참고 링크 2개가 있습니다. 원본 이미지가 없어 추측해서 대체하지 않았습니다.

## 검증

| 검증 | 결과 |
| --- | --- |
| `pnpm.cmd run build` | 현재 6개 workspace 패키지의 타입 검사와 웹·API 서버 빌드 통과. UI directive 제거 후 기존 source map 경고 해소 |
| `test:api` | API·인증 갱신·Google 인증·회사·푸시 계약 62개 통과 |
| `tsc --noUnusedLocals --noUnusedParameters` | 웹 소스 통과 |
| E2E·live E2E 타입 검사 | 모두 통과. 실제 서비스 live 테스트는 실행하지 않음 |
| 대표 브라우저 검사 | 최초 60개 중 46개 통과·10개 실패·4개 중복 폭 조합 건너뜀. 실패 원인 처리 후 10개 모두 재검증 통과 |
| 시각 기준 이미지 비교 | 정상 화면을 검토한 뒤 4개 기준 이미지 갱신. 이후 갱신 옵션 없이 다시 실행하여 4개 모두 통과 |
| 오프라인 frozen lockfile 검사 | 현재 package 선언과 잠금 파일 일치, 의존성 참조 누락 0건 |
| UTF-8 검사 | 소스·설정·문서 250개에서 잘못된 UTF-8, BOM, replacement 문자 없음 |
| `git diff --check` | Windows CRLF를 허용한 검사 통과 |

대표 브라우저 검사는 `flows.spec.ts`, `shell.spec.ts`, `tasks-design.spec.ts`, `visual.spec.ts`를 사용했습니다. 전체 수집 목록 337개를 전부 실행한 결과는 아닙니다. 부분 실행을 합산하면 기능·레이아웃 52개와 시각 검사 4개가 통과했습니다. 320·390·768·1280px의 긴 제목·선택 모드에서는 가로 넘침이 없었습니다.

최신 브라우저 결과는 `artifacts/flowra-web/playwright-report/`에서 확인할 수 있습니다. 마지막 부분 실행의 보고서이므로 앞선 기능 검사 전체를 포함하지 않습니다.

브라우저 검사는 실제 서비스 API를 변경하지 않는 모의 API 환경을 사용합니다. 실제 서비스의 저장·메일·푸시·AI 동작을 검증한 결과로 해석하지 않습니다.
